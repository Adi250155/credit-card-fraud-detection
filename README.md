

I built this project as part of my journey into Machine Learning. My main goal was to gain hands-on experience, understand how machine learning models work, and build confidence by implementing a complete ML project.

Through this project, I explored how transaction data can be used to identify potentially fraudulent activities.

What I Learned

Data loading and exploration using Pandas.

Data preprocessing and handling imbalanced datasets.

Understanding and implementing Logistic Regression.

Splitting datasets into training and testing sets.

Evaluating machine learning model performance.

Saving and loading trained models using Joblib.

Building a simple interactive application using Streamlit.

Technologies Used

Python

Pandas

NumPy

Scikit-learn

Matplotlib

Seaborn

Streamlit

Jupyter Notebook

Algorithm Used

Logistic Regression

Dataset

The project uses a credit card transaction dataset containing anonymized PCA features (V1 to V28), transaction time, amount, and a target class.

0 – Legitimate Transaction

1 – Fraudulent Transaction
